# Planering – Gaming Hub

## Idé

Jag ska skapa en webbplats som heter **Gaming Hub**. Den kommer handla om gaming och mina favoritspel.

Syftet med webbplatsen är att visa grundläggande kunskaper i HTML och CSS enligt kursen Webbutveckling 1.

---

## Mål

Målet med projektet är att skapa en fungerande webbplats med flera sidor som uppfyller alla E-krav.

---

## Sidor

Webbplatsen kommer bestå av 3 sidor:

* **index.html** – startsida med information och bild
* **games.html** – lista och tabell över spel
* **contact.html** – kontaktformulär

---

## Struktur

Projektet kommer ha följande struktur:

* HTML-filer i root-mappen
* En extern CSS-fil i en css-mapp
* Bilder i en images-mapp

---

## Design

Jag kommer använda en mörk design med gaming-tema.

Färger:

* svart (#1e1e1e)
* vit (white)
* accentfärg (gul)

Jag kommer använda grid-layout för att placera innehåll snyggt.

---

## Verktyg

* HTML
* CSS
* VS Code
* GitHub
* W3C Validator
* GlooMaps (sitemap)
* Wireframe.cc (wireframes)

---

## Arbetsmetod

Jag kommer arbeta i steg (commits) så att varje del sparas:

* Dag 1: struktur + startsida
* Dag 2: games-sida
* Dag 3: contact-sida
* Dag 4: fix + validering + sitemap + wireframes
